📱 الطريقة الثانية: استخدام Railway Dashboard (بدون CLI)
════════════════════════════════════════════════════════════════════════════════

1️⃣ افتح: https://railway.app

2️⃣ سجل دخول (أو أنشئ حساب مجاني)

3️⃣ اضغط "New Project"

4️⃣ اختر "Deploy from GitHub repo"

5️⃣ ارفع المشروع على GitHub أولاً:
   
   cd "/Users/hazemmontaser/Downloads/PS cafe"
   
   # على GitHub: أنشئ repo جديد: ps-lounge-demo
   
   git remote add origin https://github.com/YOUR_USERNAME/ps-lounge-demo.git
   git branch -M main
   git push -u origin main

6️⃣ في Railway: اختر الـ repo اللي رفعته

7️⃣ اضغط Deploy

8️⃣ انتظر 2-3 دقائق

9️⃣ خلاص! 🎉

⚙️ Environment Variables (Railway Dashboard)
════════════════════════════════════════════════════════════════════════════════

في Railway Dashboard → Variables → Add:

NODE_ENV=production
JWT_SECRET=your_random_secret_key_here_12345
CORS_ORIGIN=*

❓ مشاكل شائعة وحلولها
════════════════════════════════════════════════════════════════════════════════

❌ "Railway CLI not found"
   ✅ الحل:
      brew install railway
      
      أو:
      bash <(curl -fsSL https://railway.app/install.sh)

❌ "Permission denied"
   ✅ الحل:
      chmod +x DEPLOY_AUTOMATED.sh

❌ "Build failed"
   ✅ الحل:
      تأكد من وجود package.json في المجلد الرئيسي
      تأكد من إضافة Environment Variables

❌ "Port error"
   ✅ الحل:
      Railway بيخصص Port تلقائياً، مش محتاج تعمل حاجة
