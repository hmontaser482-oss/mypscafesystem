• اضغط على المشروع
• اضغط "Variables" tab
• اضغط "New Variable"
• أضف المتغيرات دي:

│ Variable Name       │  Value                                        │
├─────────────────────────────────────────────────────────────────────┤

│ CORS_ORIGIN         │  *                                            │
│ PORT                │  ${{RAILWAY_PUBLIC_PORT}}                     │
└─────────────────────────────────────────────────────────────────────┘

  https://mypscafesystem-production.up.railway.app

   • أنواع الأجهزة

   • مع فريقك
   • مع العملاء للتجربة

🐛 استكشاف الأخطاء
════════════════════════════════════════════════════════════════════════════════

❌ "Application Error"
   ✅ شوف Logs في Railway Dashboard
   ✅ تأكد من Environment Variables صح

❌ "Cannot connect to database"
   ✅ أعد Deploy
   ✅ تأكد من Volume settings

❌ الصفحة بيضاء
   ✅ افتح Console في المتصفح (F12)
   ✅ شوف الأخطاء واضغط Refresh
